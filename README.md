# ETHOS DES LEADERS (EDL) — Site vitrine

Site institutionnel responsive réalisé en **HTML, CSS et JavaScript natifs**.

## Lancer le site
1. Décompressez le dossier `ethos-des-leaders`.
2. Ouvrez `index.html` dans un navigateur.
3. Pour un aperçu plus pratique pendant le développement, ouvrez le dossier dans Visual Studio Code et utilisez l'extension Live Server.

Aucune compilation ou installation de dépendance n'est nécessaire.

## Fichiers
- `index.html` : structure et contenu français du site.
- `style.css` : identité visuelle bleu nuit, or et ivoire, mise en page responsive et animations discrètes.
- `script.js` : menu mobile, apparitions au défilement, création de la fiche contact vCard et formulaire avec ouverture d'un courriel.
- `documents/` : emplacement pour les documents officiels PDF.
- `images/` : emplacement pour le logo et les photographies officielles.

## À compléter avant publication
Les informations qui n'ont pas été fournies sont volontairement indiquées comme éléments à personnaliser :
- biographie détaillée et vision officielle du fondateur ;
- diplômes, titres, distinctions et références vérifiables ;
- adresse physique et modalités/horaires de rendez-vous ;
- logo officiel et photographies autorisées ;
- résumé définitif du livre, éditeur, date de parution, prix et lien d'achat ;
- titres des neuf ouvrages à venir ;
- articles, interviews et événements réels ;
- mentions légales et politique de confidentialité.
